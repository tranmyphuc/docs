AEGIS is the autonomous control plane where **security and cost finally agree**. It
maps your compliance posture *and* your cloud/SaaS waste, then **arbitrates every
conflict between them as one cryptographically auditable decision**.

This 5-minute path runs the flagship conflict end-to-end against bundled fixtures —
no cloud account, no API keys, no network.

## Prerequisites

<Card title="Rust toolchain" icon="rust" href="https://rustup.rs">
  Install `rustc` and `cargo` (a recent stable, 1.80+) via [rustup](https://rustup.rs). That's the only
  dependency — the v0.1 core is zero-dependency and builds fully offline.
</Card>

## 1. Clone and run the flagship demo

```bash
git clone https://github.com/tranmyphuc/aegis && cd aegis
cargo run -p aegis-cli -- simulate
```

You'll see the arbitration kernel resolve **200 idle Microsoft 365 E5 seats** against a
**mandatory ISO 27001:2022 A.8.15 audit-retention obligation**:

```text
AEGIS simulate — idle E5 reclamation vs. audit-log retention

Pareto frontier (feasible, non-dominated plans):
  [0] save $  9120.00/mo  coverage_loss=0  apply=["reclaim-e5-general"]

Binding constraints (why cost did not win outright):
  ✗ proposal 'reclaim-e5-regulated' on 'm365:e5:regulated' vetoed by
    mandatory control A.8.15 (E5-tier audit logging must be retained
    for the regulated cohort)

RECOMMENDED: save $9120.00/mo by applying ["reclaim-e5-general"]
Forfeited $2280.00/mo to honor mandatory compliance obligations.
```

The point: AEGIS doesn't just reclaim the cheap seats — it tells you **exactly which
control vetoed the cheaper plan** and how much money you deliberately forfeited for
compliance.

## 2. Run the full pipeline over fixtures

`scan` runs connectors → agents → arbitration against the CSV fixtures in `fixtures/`:

```bash
cargo run -p aegis-cli -- scan
```

This parses a Microsoft Graph–shaped usage report (idle-seat detection) and a
Prowler-shaped findings report (ISO 27001 control mapping), emits FinOps proposals and
compliance obligations, then arbitrates them.

## 3. Emit a tamper-evident evidence bundle

Every decision is recorded in a hash-chained, OpenTelemetry-GenAI-shaped log. Export the
control-mapped evidence bundle an auditor can verify:

```bash
cargo run -p aegis-cli -- evidence --control A.8.15
```

```json
{
  "control_id": "A.8.15",
  "chain_head": "36305bba…b1238b00",
  "verified": true,
  "decision_count": 2,
  "decisions": [ … ]
}
```

If any past decision is altered, the hash chain breaks and `verified` flips to `false`.

## 4. Try the weighted fallback strategy

The default strategy returns the full **Pareto frontier**. For very large proposal sets,
a linear weighted-scalar fallback returns a single best plan:

```bash
cargo run -p aegis-cli -- arbitrate --strategy weighted
```

## 5. Run the test suite

```bash
cargo test --workspace
```

All tests pass offline — the arbitration kernel, connectors/agents, sandbox surface, and
the evidence hash chain (including tamper-detection tests).
