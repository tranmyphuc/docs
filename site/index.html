How it works

From prompt to polished UI in three steps

Install once

Run npx uipro-cli init or drop the skill into .claude/skills. Your assistant auto-detects it.

Ask naturally

"Build a SaaS dashboard" or "what palette fits a wellness app?" The skill activates automatically for any UI/UX task.

Get reasoned output

A BM25 search engine returns a full design system — pattern, style, colors, type and effects — with the anti-patterns to avoid.

Stack-aware

Implementation guidance for your framework

Recommendations come with code-level best practices tailored to the stack you actually ship in.
